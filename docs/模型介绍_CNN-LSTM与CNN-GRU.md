# 模型介绍：CNN-LSTM 与 CNN-GRU（结合本项目）

> 用途：大创汇报/论文/结题材料中"模型方法"一节的素材。所有数字均取自本工作区实测
> （`results/controlled_gru/`，受控实验 `controlled_gru_v1`，2026-10-11），
> 引用时与 `docs/CNN-GRU_实验计划书.md`、`results/controlled_gru/report.md` 保持一致。

## 1. 两个模型在本项目中处于什么位置

本项目要回答的问题是：**用西昌 32 井过去 60 天的水氡观测（9 通道特征），预测下一天的水氡值**。两个模型的完整数据流完全相同，唯一差别是中间的"时序汇总单元"：

```
输入窗口 [60天 × 9通道]
   ├─ 9通道 = 原始水氡 + 7/14/30日滚动均值与标准差 + 一阶/二阶差分（全部只用过去信息）
   ▼
CNN 前端（两模型共用）
   ├─ Conv1d(9→64, 核3) + ReLU + MaxPool(2)
   ├─ Conv1d(64→32, 核3) + ReLU + MaxPool(2)
   └─ 输出 [约15天 × 32通道]：把60天原始波形压缩成15个"摘要时刻"，每个时刻32维
   ▼
时序单元（★ 唯一差异）
   ├─ CNN-LSTM：nn.LSTM(32→64)，单层单向   → 35,169 个可训练参数
   └─ CNN-GRU ：nn.GRU(32→64)，单层单向   → 28,897 个可训练参数
   └─ 都取最后一个时间步的输出，得到 64 维"当前状态表示"
   ▼
回归头（两模型共用）
   └─ Dropout(0.4) → Linear(64→32) → ReLU → Linear(32→1) = 明日水氡预测值
```

**为什么 CNN 之后还需要一个循环网络？** 卷积擅长提取局部形态（比如几天内的台阶、脉冲形状），但它对"现在处于年内什么阶段、最近一个月的整体水平相对过去是高是低"这类**跨时段的状态记忆**没有显式机制。循环单元维护一个随日期更新的隐状态，正好承担"读完 60 天摘要后，记住当前水文背景"这个角色。这对应水氡观测的两种成分：**长程背景**（年变、季节、丰枯水期）和**短期扰动**（降雨、抽水、仪器、可能的构造信息）——前者需要"记住"，后者需要"适时遗忘"。

## 2. LSTM：长短期记忆网络

LSTM（Long Short-Term Memory，Hochreiter & Schmidhuber, 1997）是为解决普通 RNN"记不住远期信息、训练时梯度消失"而设计的。它的核心是**一条贯穿时间的细胞状态 c_t（记忆传送带）+ 三个门控**，每个门都是一个取值 0~1 的小网络，控制信息流：

| 门 | 作用 | 直观理解 |
|---|---|---|
| 遗忘门 f_t | c_t = f_t ⊙ c_{t-1} + … | 旧记忆保留多少（0=清空，1=全留） |
| 输入门 i_t | + i_t ⊙ c̃_t | 今天的新信息写入多少 |
| 输出门 o_t | h_t = o_t ⊙ tanh(c_t) | 对外披露多少记忆 |

其中 c̃_t 是由 tanh 生成的候选新记忆。**加性更新**（c_t 是"旧记忆 + 新记忆"的和，而不是连乘）是它能保持长期记忆的数学根源——梯度可以沿 c 这条加法路径回传而不易衰减。

在本项目中，LSTM 每天读入 CNN 摘要的 32 维向量，读完整 15 个摘要时刻后，最后一天的隐状态 h（64 维）就是"截至昨日的井内水氡状态"，交给回归头换算成明天的值。它有 4 组权重矩阵（对应 3 个门 + 1 个候选记忆），合计 25,088 个参数，占整个模型 35,169 的 71%。

## 3. GRU：门控循环单元

GRU（Gated Recurrent Unit，Cho et al. 2014，即计划书引用的 arXiv:1412.3555）是 LSTM 的**精简变体**：去掉独立的细胞状态，把三个门合并成两个，记忆直接存在隐状态 h_t 里：

| 门 | 作用 | 直观理解 |
|---|---|---|
| 更新门 z_t | h_t = (1−z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t | 一个门同时管"保留旧状态多少、写入新状态多少" |
| 重置门 r_t | h̃_t = tanh(W·[r_t ⊙ h_{t-1}, x_t]) | 计算候选新状态时，参考多少旧记忆 |

对比 LSTM：GRU 把"遗忘门 + 输入门"融合为一个更新门（两者本来职责就高度相关），并且不再区分"对外输出 h"和"内部记忆 c"。少了一组矩阵，参数从 4 组降到 3 组：本项目 GRU 时序单元 18,816 个参数，整个模型 28,897 个，**比 LSTM 版少 6,272 个（约 17.8%）**。

Cho 等人 2014 年的原始比较结论是：GRU 与 LSTM 在多数任务上表现相当、GRU 更省。但注意（这也是计划书明确写下的边界）：**"在别的任务上相当"不构成"在西昌 32 井水氡上必然更好"的证据**——所以本项目做的是受控实测，而不是引用文献下结论。

## 4. 异同一览（结合本项目实测）

| 维度 | CNN-LSTM | CNN-GRU |
|---|---|---|
| 门数量 | 3（遗忘/输入/输出）+ 独立细胞状态 | 2（更新/重置），无独立细胞状态 |
| 权重组数 | 4 组 → 时序单元 25,088 参数 | 3 组 → 时序单元 18,816 参数 |
| 全模型参数 | 35,169 | 28,897（少 17.8%） |
| 记忆机制 | 加性细胞状态，长程记忆更"专设" | 隐状态直接线性插值旧/新，结构更简 |
| 训练协议 | 完全一致：Adam lr=4.501e-4、HuberLoss、batch 128、patience 15、早停看验证段 | 同左 |
| 五种子平均测试 MAE | 0.176016 | **0.152021（改善 13.6%）** |
| 种子间 MAE 范围 | 0.146~0.226（s44 劣化到 0.226） | 0.149~0.158（明显更稳） |
| 改善种子数 | — | 4/5（唯一例外 s45 差 2.0%） |
| 逐年表现 | — | 5 个测试年全部不劣于 LSTM（−2.5%~−17.8%） |
| 平均单次训练耗时 | 15.7 s（CPU） | 22.4 s（CPU；GRU 平均早停更晚、跑的 epoch 更多，单 epoch 成本相近） |

一句话概括差异：**LSTM 用三个门和一条独立的记忆传送带换取更细的记忆控制；GRU 用两个门直接在隐状态上做新旧插值，用更少的参数达到相近甚至（在本站本任务上）更好的效果。**

## 5. 本项目实测结果说明了什么

受控实验（唯一差异 = 时序单元，5 个配对种子、同一数据窗口、同一洗牌顺序）显示，在这个 4,143 天的水氡单序列上：

1. **GRU 更准也更稳**：五种子平均 MAE 0.1520 vs 0.1760，且 LSTM 的表现对随机种子敏感（一个种子上 MAE 恶化 28%），GRU 五个种子挤在 0.15 附近——对需要固定一个模型上线/出报告的场景，稳定性本身就有价值。
2. **参数更少反而更好**：提示 60 天窗口的时序汇总并不需要 LSTM 那么多的门控容量，GRU 的简化没有损失必要记忆能力。
3. **预先登记的三条筛选规则全部满足**，按计划书口径只能得出"**GRU 值得做后续独立验证**"，不能写成"GRU 已被证明优于 LSTM"——因为 2022-05 之后的测试段此前参与过 v6.1 选型，本轮属回顾性探索；模型还没有经历"冻结后逐日滚动"的独立前瞻检验。

## 6. 汇报可直接用的一句话版

> 我们用完全相同的 CNN 前端、输入特征和训练协议，只把时序汇总单元从 LSTM 换成 GRU，在 西昌 32 井 2015–2026 年水氡日值上做了 5 种子配对对照实验。GRU 以少 18% 的参数取得 13.6% 的测试 MAE 改善，且跨随机种子显著更稳；受限于测试段曾被历史版本用于选型，该结果定性为回顾性探索，结论是 GRU 值得进入后续独立前瞻验证，而非直接替换正式模型。
