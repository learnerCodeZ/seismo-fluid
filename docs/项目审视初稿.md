## 3. 技术架构（现状）

```
原始数据 OriData*（只读，外置）
        ↓ src/data/ 管道
data/clean/long.csv
        ↓ 滑窗 + 标准化
CNN-LSTM / E_cosine（PyTorch CPU）
        ↓ 预测残差
LOF（自参照 novelty，q=0.98）
        ↓
异常事件 → 气象归因 + 目录检索 → 震例表
        ↓
results/v61_*  →  web/ FastAPI + ECharts
```

**既定纪律（不要回退）**

1. 异常检测走无监督（预测残差 + LOF），不用监督分类  
2. LOF 自参照，不用训练段当密度参照  
3. NaN 特征行整行丢弃，禁止插值毒化 LOF  
4. 时序按时间切分，禁止随机打乱  
5. 原始数据只读；结果必须落盘 `results/`

## 4. 当前主结果（务必分场景引用）

### 4.1 预测（65/35，测试段 2022-05-16 起）

| 模型 | R² | 原始尺度 RMSE (Bq/L) | 备注 |
|------|-----|----------------------|------|
| Naive | 0.874 | — | 持久性 |
| RF | 0.880 | — | |
| LSTM-RF | 0.878 | — | |
| CNN-LSTM tuned | 0.901 | 0.187 | |
| **E_cosine ★** | **0.905** | **0.183** | 主模型 |

**Caveat（论文必带）**：整体 R² 被 2023–2024 高方差年抬高；2025–2026 序列几乎持平（年 std≈0.15），R² 为负或零。  
**必须分年报**，或以 RMSE/MAE + 残差图为主指标。网页「按年 R²」表已内置该说明。

### 4.2 异常与震例

- LOF 事件 **5** 个（q=0.98，29 异常点）  
- 5/5 在后续 90 天内有 M4.5+；4/5 有 M5+  
- 六个关键地震：3 场在训练段；芦山窗口不完整；**两场泸定公平可检 → 未检出前兆**  
- 结论表述：方法有效 + 对预设大震阴性，**两条都要写**

### 4.3 优化配方（E_cosine）

在标准 CNN-LSTM 上叠加：9 通道特征（raw + roll mean/std + diff）+ RobustScaler + Huber + CosineAnnealing。  
超参沿用 v6.0 Optuna（未在 65/35 下重搜）。
