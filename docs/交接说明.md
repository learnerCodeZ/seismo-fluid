## 2. 环境与依赖

- **建议 Python**：3.11–3.14（本机验证过 3.14.5；环境约定 **不用 pyarrow / PyYAML**，产物一律 CSV + JSON）
- **安装依赖**：

```bash
cd <项目根目录>
python -m pip install -r requirements.txt
# Web 需要（requirements 已含）:
python -m pip install fastapi uvicorn
```

- **torch**：`requirements.txt` 默认 CPU 版即可满足本项目规模。若 `torch==2.13.0+cpu` 装不上，可改用当前稳定 CPU 轮子，先保证 `import torch` 成功。

### 10 分钟自检

```bash
# 1) 合成数据端到端（不依赖真实原始数据）
python smoke_test.py

# 2) 若已有 data/clean/，可读主表确认格式
python -c "import pandas as pd; df=pd.read_csv('data/clean/long.csv'); print(df.head()); print(len(df))"

# 3) Web（需要 results/ 下的结果文件才有完整图表）
python web/app.py
# 浏览器打开 http://127.0.0.1:8002/
```

`smoke_test.py` 通过 → 依赖与核心训练环正常。  
`long.csv` 能读 → 清洗数据可用。  
Web 能起 → 前后端通；某一页空图多半是 `results/` 不全，见第 4 节。

## 3. 路径配置（必做）

所有绝对路径集中在 **`configs/paths.json`**（仓库里若已有本机路径，**不要提交你的机器路径**）。

1. 复制示例：

```bash
# Windows
copy configs\paths.example.json configs\paths.json
```

2. 修改两个字段：

| 字段 | 含义 |
|------|------|
| `data_root` | 原始数据根目录：其下应有 `OriData`、`OriData2`、`OriData3` |
| `project_root` | 本仓库在你机器上的绝对路径 |

3. **不要改** `external.*` / `internal.*` 的相对名，除非你们整体改协议。

原始数据布局（只读，勿写）：

```text
<data_root>/
├── OriData/      # 云南台站流体日值 TXT 等
├── OriData2/     # 整理后的 xlsx（含西昌32井长序列）
├── OriData3/     # 西昌气象 + 地震目录等
└── Papers/       # 文献 PDF（可选）
```

## 5. 当前结论速览（便于对接，勿当最终论文定论）

- **主模型口径 v6.1**：CNN-LSTM **E_cosine**（9 特征 + RobustScaler + Huber + Cosine），65/35 切分（测试段约自 2022-05-16）。  
- 整体 R²≈0.905 **有水分**：分年 R² 波动大，论文须分年报或以 MAE/RMSE + 残差为主。  
- **无监督路线**：预测 → 残差 → **LOF**；不做监督分类。  
- LOF 检出事件与后续 M4.5+ 有对应；**关键大地震前兆可为阴性**（科学结论，不是失败）。  
- 多变量实验：水氡单变量往往仍最优；水位/气象特征不一定提升。  

技术决策与禁止回退项：**始终先读 `AGENTS.md`**。

## 6. 协作纪律（高优先级）

1. **原始数据只读**：`data_root` 下 `OriData*` 禁止改写。  
2. **`data/clean/` 禁止手改**：只通过 `src/data/run_pipeline.py` 再生。  
3. **时序按时间划分**，禁止 `train_test_split(shuffle=True)` 类打乱。  
4. **异常检测保持无监督**；阈值用敏感性实验确定，禁止拍脑袋分位数写死进论文。  
5. **结果落盘**：实验输出写入 `results/<实验名>/`，口头结果无效。  
6. **提交**：不要提交 `paths.json` 里的个人绝对路径、模型权重、整个 `results/` 除非团队明确约定。  
7. 文档中文 Markdown；文献数值保留出处。

## 9. 常见故障

| 现象 | 处理 |
|------|------|
| `FileNotFoundError` 指向 `OriData...` | `configs/paths.json` 的 `data_root` 未改对 |
| Web 预测页空/报错 | 缺 `results/v61_*`；拷贝结果包或重跑 v6.1 脚本 |
| 页面数字像旧版 | 浏览器 `Ctrl+F5` |
| 端口 8002 被占用 | 已在跑则直接访问；否则改端口见 `web/README.md` |
| `torch` 安装失败 | 换 CPU 轮子/相近版本；先保证可 import，再对齐 `requirements.txt` |
| 读 xlsx 缺 `openpyxl` | `pip install openpyxl` |
