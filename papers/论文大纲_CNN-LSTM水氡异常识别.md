## 2. 摘要（约 300 字，按此骨架写）

1. **问题**：水氡动态受构造与气象耦合影响，非线性非平稳，震前微弱异常难从背景中分离。  
2. **方法**：西昌 32 井水氡日值（2015-01—2026-05，4143 d）；65/35 时间切分（测试自 2022-05-16）；CNN-LSTM 预测，训练配方优化（多尺度滑动特征 + RobustScaler + Huber + CosineAnnealing，记 E_cosine）；预测残差 LOF（k 动态，q=0.98，附 0.98–0.995 敏感性）；气象降水排除；地震目录 90 d 窗口对应。  
3. **结果**：E_cosine 测试段 R²=0.905、RMSE≈0.18 Bq/L；**同一西昌井、同一 65/35 测试段**下略优于 LSTM-RF 复现基线（0.878），但与刘慧等在武都殿沟泉的论文结果**不可跨研究区直接比较**。LOF 识别 5 个异常事件，均在后续 90 d 内对应 M≥4.5 地震（4 次事件后有 M≥5）。对测试段内可完整检验的 2022-09-05 泸定 M6.8、2023-01-26 泸定 M5.6，**未检出工作阈值下的震前异常**。  
4. **结论**：残差 LOF 链路可稳定提取候选异常；西昌 32 井水氡对上述两次泸定地震可能无显著前兆响应。整体 R² 受年际方差影响大，须分年报告。

**关键词**：水氡；地震前兆；CNN-LSTM；局部离群因子；残差异常检测；西昌

### 3 研究方法（对应刘慧 §3，本文核心差异章）

#### 3.1 总体技术路线

```
清洗日值 → 时间切分(65/35) → 特征与标准化
    → CNN-LSTM 预测下一时刻水氡
    → 残差 r = y − ŷ
    → LOF(残差 7 日形态特征) → 阈值 → 事件聚合
    → 气象排除 + 目录 90 d 对应
```

- 明确：地震目录**不参与训练**，仅用于分析阶段对应。  
- 明确：评估指标 RMSE/MAE/MAPE/R²；**并报分年 R²**。

#### 3.2 时序划分

- 65/35：训练 2015-01—2022-05-15；测试 2022-05-16—2026-05-05。  
- 选择理由：使芦山 M6.1、泸定 M6.8、泸定 M5.6 进入可分析时段（与刘慧「训练/预测期」写法对齐）。  
- 验证集：训练段尾部 15%（时间顺序，不打乱）。

#### 3.3 预测模型

##### 3.3.1 基线（健全性检查）

- Naive 持久性、RF（与文献同构）、LSTM、LSTM-RF（复现刘慧级联）。  
- 目的：排序检查 + 论文对照，不是主结果。

##### 3.3.2 CNN-LSTM 主模型

```
Input [B,60,C] → Conv1D(64,k3)→ReLU→MaxPool
→ Conv1D(32,k3)→ReLU→MaxPool → LSTM(64) → Dropout → Dense → ŷ
```

- 窗长 60 d、步长 1 d（与刘慧一致，便于对比）。

##### 3.3.3 训练配方优化（记 **E_cosine**）

| 模块 | 设置 | 动机 |
|------|------|------|
| 输入特征 C=9 | raw；roll mean/std 7/14/30；一阶、二阶差分 | 多尺度水平/波动/涨跌 |
| 标准化 | RobustScaler（中位数、IQR） | 抗尖峰 |
| 损失 | Huber | 大误差不过度主导 |
| 学习率 | Adam + CosineAnnealing | 逃离尖锐局部解 |
| 超参 | conv(64,32)，hidden=64，dropout=0.4，lr≈4.5e-4，batch=128 | Optuna 结果沿用 |

- 写清：A–F 消融设计（表 3），选定 E 的依据。

#### 3.4 残差 LOF 异常检测（对齐刘慧口径，写清差异）

- 特征：残差 7 日滑动窗形态向量。  
- k：√n 为基准，落在残差角色区间（约 5–25；本例 k=25）。  
- novelty 自参照打分；阈值工作值 **q=0.98**，敏感性 {0.98, 0.985, 0.987, 0.99, 0.995}。  
- 相邻异常点 ≤3 d 合并为事件。  
- 与刘慧：其文 q=98.7%，本文工作值 98% 并报敏感性，避免「一个阈值定生死」。

#### 3.5 干扰排除与震例对应

- 事件时段累计降水 >10 mm → 标「气象干扰/待确认」。  
- 事件结束后 90 d 内目录检索 M≥4.5 / M≥5。  
- **双向检验**：  
  - 正向：LOF 事件 → 后续地震；  
  - 反向：关键地震前 90 d → 有无事件。  
- 自动统计标记 Z-score / IQR / MAD 作对照（说明与 LOF 低重合、互补）。

### 5 讨论（本项目比刘慧文更该写透的一章）

#### 5.1 预测能力与指标口径

- 为何整体 R²≈0.90 不能直接当「预测很强」：年际方差结构 + 自相关。  
- 建议同行报告规范：整体 + 分年 + 绝对误差。

#### 5.2 阴性震例的科学含义

- 可能解释（任选 2–3 条展开，避免武断）：  
  1. 井—震构造耦合弱或震中距/方位不利；  
  2. 前兆幅度低于 LOF 在 q=0.98 下的检出能力（附低阈值试探表）；  
  3. 前兆形态非「残差局部离群」而是缓变趋势（LOF 不敏感）。  
- 与刘慧文三次阳性对照：区域、井孔、震源机制、数据长度均不同，**不宜简单比检出率**。

#### 5.3 方法局限

- 单井单测项为主；未完成 SK3 多参数联合消融作为主文结果；  
- 2024-04 事件与 M5.0 同日，**震前/同震**需谨慎；  
- 未做 Molchan 等前兆效能定量检验（可写「下一步」）；  
- 超参未在最终切分上重搜 Optuna（诚实声明）。

#### 5.4 与 LSTM-RF 范式及刘慧等结果的关系

- 呼应 `papers/刘慧2026_论文总结.md` §7：端到端局部形态 vs 级联可解释；异常阶段同用 LOF。  
- **预测层（本井同切分）**：E_cosine R²=0.905 > LSTM-RF 0.878 > Naive 0.874；差距真实但不悬殊。  
- **前兆层（跨研究）**：刘慧文目标震例为阳性提取；本文泸定公平可检为阴性——**不能合并成「方法优劣」结论**，应讨论井—震耦合、震中距/方位、阈值灵敏度、前兆形态（突变 vs 缓变）等。  
- 写作定位：本文是 **同范式在另一口井上的检验 + 训练配方消融 + 指标口径改进**，不是对 LSTM-RF「算法竞赛式」的超越声明。

### 6 结论

1. 构建了「清洗 → 65/35 → CNN-LSTM/E_cosine → 残差 LOF → 气象与目录对应」可复现流水线。  
2. E_cosine 在同切分下优于基线与未优化 CNN-LSTM；优化关键在稳健标准化与学习率调度。  
3. LOF 提取 5 个候选异常事件，后续 90 d 内均有 M≥4.5 地震对应。  
4. 对测试段内可完整检验的两次泸定地震未识别出前兆异常；西昌 32 井水氡对此类事件的指示意义有限或低于检测阈值。  
5. 整体 R² 受年际方差强烈调制，水氡预测评估应强制分年报告。
