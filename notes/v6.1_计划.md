## 二、CNN-LSTM 调参计划

### 2.1 当前参数与 R²=0.6748

| 参数 | 当前值 | 调参方向 |
|------|--------|---------|
| Conv channels | (64, 32) | (128, 64) 或三层 (64, 64, 32) |
| LSTM hidden | 64 | 128、256 |
| Dropout | 0.3 | 0.1~0.5 网格搜索 |
| Learning rate | 1e-3 | 5e-4、1e-4 + CosineAnnealing |
| Patience | 15 | 20~30 |
| Window | 60 | 30/90/120 |
| Batch size | 64 | 32、128 |
| 验证集比例 | 15% | 10%、20% |

### 2.2 调参方案

- 使用 **Optuna** 自动调参（50~100 次试验）
- 定义搜索空间：conv_channels、lstm_hidden、dropout、lr、batch_size
- 目标函数：验证集 R² 最大化
- 保存最优参数到 `configs/exp_cnn_lstm_best.json`

### 2.3 R²=0.85 可行性分析

| 因素 | 当前 | 改进空间 |
|------|------|---------|
| 数据量 | ~2900 天（8 年） | 偏小，但已充分利用 |
| 特征维度 | 水氡单变量 | 多变量实验显示单变量最优 |
| 网络深度 | 2 层 CNN + 1 层 LSTM | 可加深 |
| 学习率策略 | 固定 1e-3 | CosineAnnealing/ReduceLROnPlateau |
| 早停策略 | patience=15 | 可放宽至 20~30 |
| 标准化 | Z-score | 可尝试 MinMax / Robust |

**现实判断**：R²=0.85 在水氡预测领域非常高水平（文献 LSTM-RF ~0.7）。通过调参 + 更大窗口，0.75~0.80 可期。若论文需要 0.85+，需考虑：
- 更长时间序列数据（10+ 年）
- 更多站点数据联合建模
- 或接受 0.75+ 配合异常检测效果作为论文成果

### 2.4 深度优化策略（v6.1 执行）

#### 策略 A：特征工程（最可能有效）

当前只用原始水氡值作为输入，增加衍生特征：

| 特征类型 | 具体特征 | 窗口 |
|---------|---------|------|
| 滑动均值 | 7/14/30 天滚动均值 | 7, 14, 30 |
| 滑动标准差 | 7/14/30 天波动性 | 7, 14, 30 |
| 变化率 | 一阶差分（日变化量） | 1 |
| 加速度 | 二阶差分（变化的加速度） | 1 |
| 季节分量 | STL 分解的趋势+季节+残差 | - |

**预期效果**：R² 提升 0.03~0.08

#### 策略 B：标准化方式改进

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| Z-score（当前） | (x-mean)/std | 正态分布，对离群值敏感 |
| **RobustScaler** | (x-median)/IQR | 对离群值鲁棒，推荐 |
| MinMaxScaler | (x-min)/(max-min) | 有界数据 |

**预期效果**：R² 提升 0.01~0.03

#### 策略 C：损失函数改进

| 损失函数 | 特点 | 适用场景 |
|---------|------|---------|
| MSE（当前） | 对大误差惩罚重 | 正态分布误差 |
| **Huber Loss** | 对小误差用 MSE，大误差用 MAE | 有离群值时更鲁棒 |
| Smooth L1 | 类似 Huber | 通用 |

**预期效果**：R² 提升 0.01~0.02

#### 策略 D：学习率调度

| 调度策略 | 特点 |
|---------|------|
| 固定 lr（当前） | 可能陷入局部最优 |
| **CosineAnnealing** | lr 余弦衰减，周期性回暖 |
| ReduceLROnPlateau | 验证损失停滞时自动降低 lr |

**预期效果**：R² 提升 0.01~0.03

#### 策略 E：多模型集成

- 训练 5 个不同种子（42, 123, 456, 789, 1024）的 CNN-LSTM
- 取平均预测：y_pred = mean(y_pred_1, ..., y_pred_5)
- 减少单次训练的随机方差

**预期效果**：R² 提升 0.01~0.02

### 2.5 综合预期

| 优化组合 | 预期 R² | 提升幅度 |
|---------|---------|---------|
| 当前基线 | 0.6810 | - |
| + 特征工程 | 0.71~0.76 | +0.03~0.08 |
| + RobustScaler | 0.72~0.77 | +0.01~0.03 |
| + Huber Loss | 0.73~0.78 | +0.01~0.02 |
| + 学习率调度 | 0.74~0.79 | +0.01~0.03 |
| + 集成 | 0.75~0.80 | +0.01~0.02 |
| **全部叠加** | **0.75~0.82** | **+0.07~0.14** |

## 三、Train/Test 切分调整

### 3.1 当前问题

当前 80/20 切分（训练 3314 天，测试 829 天），测试段为 **2024-01~2026-05**。
用户提供的 6 个关键地震全部在 2023 年之前，不在测试段内，无法验证。

### 3.2 调整方案

| 比例 | 训练段 | 测试段 | 测试段内覆盖的地震 |
|------|--------|--------|------------------|
| 80/20（当前） | 2015~2024-01 | 2024-01~2026-05 | 无 |
| 70/30 | 2015~2022-12 | 2022-12~2026-05 | 2023-01-26 泸定 M5.6 |
| **65/35（推荐）** | 2015~2022-05 | 2022-05~2026-05 | 2022-06-01 芦山 M6.1、2022-09-05 泸定 M6.8、2023-01-26 泸定 M5.6 |
| 60/40 | 2015~2021-10 | 2021-10~2026-05 | 2022-01-02 宁蒗 M5.5、2022-06-01 芦山 M6.1、2022-09-05 泸定 M6.8、2023-01-26 泸定 M5.6 |

**决定：采用 65/35**，覆盖 3 个大地震（含泸定 M6.8），训练集仍有 ~7 年数据。

- 需要重新训练所有模型（RF、LSTM、LSTM-RF、CNN-LSTM）
- 需要重新运行 Optuna 调参

## 四、数据标记计划

### 4.1 路径 A：自动标记（推荐，v6.1 执行）

使用统计方法自动标记异常点：

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| Z-score > 3 | 偏离均值 3 个标准差 | 正态分布数据 |
| IQR | 超过 Q3+1.5×IQR 或低于 Q1-1.5×IQR | 非正态分布 |
| 滑动窗口 MAD | 中位数绝对偏差 | 对离群值鲁棒 |

**计划**：
- 对水氡原始序列、CNN-LSTM 残差序列分别做三种标记
- 输出 `labels_auto.csv`：date、value、zscore_flag、iqr_flag、mad_flag
- 作为 LOF 检测结果的对照参考

### 4.2 路径 B：人工+地震对应标记（后续）

- 结合地震目录，对震前 90 天窗口人工核实
- 优点：标签质量高；缺点：耗时
- v6.2 或论文阶段再做
